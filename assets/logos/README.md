# Logos / monogrammes

Les fichiers de ce dossier sont des **monogrammes géométriques Céaki**
— initiales + barres lime/corail/feuille. Ce ne sont **pas** des
reproductions de logos de marques déposées.

Pour brancher un vrai logo sourcé :

1. Déposer le fichier ici (PNG/WebP).
2. Renseigner `logoAsset` + `logoSource` (licence) sur la marque dans
   `assets/library/library.json`.
3. Ou utiliser `logoUrl` https — l’app met en cache localement, sans
   tracking.
