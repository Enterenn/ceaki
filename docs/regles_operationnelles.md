# Règles Opérationnelles (Strictes)

- **Économie de tokens** : Ne lis jamais de fichiers de code sans besoin direct. Concentre les lectures et réponses uniquement sur le strict nécessaire.
- **Rapports** : Après chaque tâche exécutée, fais un retour concis (synthétique mais précis).
- **Gestion des commits** : Aucun `git commit` ou `git push` sans validation préalable.
- **Commentaires dans le code** : Minimum de commentaires. Uniquement ceux nécessaires si une logique métier est complexe.
- **Tests unitaires** : N'écris des tests unitaires QUE sur les points critiques de l'application. Pas de tests systématiques sur les composants UI simples ou les fonctions triviales.
- **Réponses** : Sois extrêmement concis. Pas d'explications théoriques longues.
